# Roadmap

以验收结果推进，不承诺未经验证的发布日期。勾选表示实现及相应回归已完成，不等于真实账号端到端验收。

## 1. 可靠的恢复结果

- [x] 明确 authorized / expired / unknown / missing；缺少目标行不得成功。
- [x] 绑定机器人身份、目标权限窗口和确认弹窗。
- [x] 修复进程激活、负坐标和续期后状态保存。
- [x] 探针/保活子进程有界超时、可靠互斥、恢复原 monitor 状态。
- [x] 稳定 JSON 输出和非零失败退出码，覆盖非 850003 告警。

**验收：** 加载不完整、错 bot、点击失败、网络故障均不误报健康；操作后有效期和相应 CLI 探针一致。

## 2. 独立可部署的预续期

- [x] 内聚 AX 适配层，明确依赖版本；bridge 消息/通知可选。
- [x] 配置校验和不操作 GUI 的 doctor。
- [ ] 缓存状态查询与数据新鲜度协议。
- [ ] 稳定进入目标 bot 管理页，避免固定屏幕坐标。
- [x] 将已验证的取消/重授流程封装为逐行状态机（实验性现有窗口模式）。
- [x] 取消后的恢复优先；失败留证并提示人工，不继续取消其他行。
- [x] 目标控件自动滚动、无窗口同名进程过滤、通讯录重复标题识别。
- [x] 单账号文档读写及通讯录三项独立脚本预续期，重开页面复核（2026-09-22）。
- [ ] 新版续期后接入真实业务 API 复探，补充通讯录验证。
- [ ] 独立验证基于到期时间的预续期调度；当前每小时保活仅做过期恢复。
- [ ] 调用方恢复协议及幂等重试示例。

**验收：** 干净 Mac 可按说明部署；预续期前后身份/权限范围一致；中途故障可恢复；并发调用只产生一个 GUI 操作流程。

## 3. 跨周期验证与发布

- [ ] 至少 2—3 个自然七天周期，分别记录读/写结果、恢复耗时和人工介入。
- [ ] 验证重启、窗口变化、消息干扰与调度环境。
- [ ] 发布脱敏演示、兼容性矩阵、版本化变更说明。
- [ ] 接受外部使用者复现并据此扩大支持范围。

**验收：** 证据足以说明具体支持的环境、成功条件与失败边界，再发布相应版本；不以结构 CI 通过代替实机验证。

## 暂不扩展

Linux/Windows GUI、多租户远程恢复服务、通用桌面自动化平台均不在当前优先范围。官方若提供新的能力状态或续期接口，优先保留上层恢复协议并替换底层实现。
