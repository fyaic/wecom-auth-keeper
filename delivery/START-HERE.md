# 把这个文件夹交给你的 AI 助手

这是企业微信 Bot 权限续期工具的 **macOS 试点分发版**。已在 macOS arm64、企业微信 5.0.13/95049 中文版完成后台真实续期、跨企业切换及自动关页。其他设备仍需逐机验收；Windows 尚无自动续期后端，请勿作为 Windows 可用版分发。不是企业微信官方产品。

1. 从维护者取得 ZIP 和校验值，解压到固定位置（不要放临时下载目录后随手删除）。
2. 在 Codex、WorkBuddy 等有本机文件和终端权限的工具里打开整个文件夹，发送下面这段话。
3. 你只需要说明：用哪个企业、哪个机器人、哪些业务权限，并完成必要的一次性系统授权。不要提供 Bot Secret、密码或 token。
4. 将该机器人的官方续期链接保存在**这台设备与目标 Bot 的私聊**中；助手应核对身份、在本机聊天记录中确认能找回。首次没有链接时，助手会先说明，再按你的授权准备入口。

可复制给 AI：

> 请先阅读 delivery/AGENT-INSTALL.md，按它为这台设备安装企业微信 Bot 自动续期。先检测系统、客户端版本、已有定时任务和 CLI 当前绑定的机器人，再与我确认企业、机器人及需要的业务权限。不要复制别人的身份或配置，不要自动扩大授权范围。支持时使用本机私有配置，默认每小时检查、提前24小时续期，结束关闭权限页。必须区分“配置完成”“后台检查通过”和“实际续期通过”，给我一份简短结果；如果是 Windows 或页面不匹配，明确说明缺少什么，不要假装成功，也不要在未知布局上硬套坐标。

正常运行需要电脑开机、企业微信登录且桌面可操作。AI 只负责安装和诊断，定时续期由脚本执行，不需要每周重新打开 AI。

机器人在多个企业下重名时，名字不能代替身份核验。首次缺少授权链接或系统辅助功能权限时，助手可能需要你完成一次操作。以后若客户端升级导致结构变化，应报告失败并重新验收，不让助手无限重试点击。

若收到“授权过期 / 850003”，先检查业务权限；这不等于数据库、网络或整套机器人服务损坏。续期可能恢复相关能力，但不保证解决所有无响应问题。
