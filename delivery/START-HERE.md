# 把这个文件夹交给你的 AI 助手

这是企业微信 Bot 自动续期工具的 **macOS Agent 安装包**。远端 Kimi Code 已使用包内脚本完成真实续期和自然定时触发，实测客户端为企业微信 **5.0.13/95049 中文版**。每台业务设备仍由安装 Agent 验收后启用；Windows 暂不支持。不是企业微信官方产品。

**使用前提：这台 Mac 的企业微信登录 Bot 创建者的主账号，续期的是这个主账号自己创建的 Bot。** 只有 CLI 配置或能调用 Bot 的业务账号，不满足这个前提。主账号仍需处于正确组织，且电脑开机、桌面可操作。

解压到固定位置，用 Codex、WorkBuddy 等能够操作本机文件、终端和企业微信的 Agent 打开整个文件夹，发送：

> 请按这个项目的 AGENTS.md 为我安装企业微信 Bot 自动续期。先查清本机 Bot、组织和已有 CLI 配置，维护我指定且由当前登录主账号创建的 Bot；把续期入口放在本机与它的私聊中。只维护我需要的权限，保留其他 Bot 和服务。请完成真实续期、自然定时触发、自动关页的实测，再启用每小时检查、到期前24小时续期，并告诉我结果和停用方式。遇到失败请定位并修复复测，不要仅登记任务就报成功。

可以补充一句：“我要用于××企业的××业务，需要文档/消息/微盘等权限。”已经有 Bot 就告诉 Agent 名称；不知道时让它先查看本机配置与企业微信。有多个候选时，它应给出查到的具体选项，不让你抄 ID 或配置文件。

安装成功后无需让 AI 常驻；系统定时任务调用 Python 脚本，按各权限自己的有效期维护，并关闭本次权限页。支持一份配置维护多项权限，多 Bot 使用各自配置和任务。最新远端验收只授予并验证“发送消息”，其他权限须在实际使用设备逐项验证。详细证据见 [VALIDATION.md](VALIDATION.md)。Codex/WorkBuddy 可按相同协议安装，本轮实际执行安装演练的 Agent 是 Kimi Code。

已有匹配 CLI 绑定时不需要重新扫码。如果你已创建Bot、只是这台电脑尚未接入它，Agent应先检查该Bot的现有API配置和官方手动接入方式，保留其他Bot的配置；不能默认要求扫码或重建。系统辅助功能和首次新增业务权限可能需要你确认。日常定时续期由脚本运行，无需每周再打开 AI。电脑需要开机、企业微信登录且桌面可操作。收到新客户端不兼容提示时需重新验收，不能保证任意 Mac/企业微信版本均可运行。

设备上的 CLI 已绑定，不代表当前登录的企业微信账号有权给它续期。若官方页面要求“机器人创建者”，Agent 应保留配置并说明需要哪个身份/组织，不能要求你重新创建 Bot 来掩盖问题。只有本机真实续期和定时触发均通过，才能报告安装完成。
