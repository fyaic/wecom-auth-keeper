# Security policy

This is experimental desktop automation. No supported-version security SLA is currently offered. Check [known limitations](docs/known-limitations.md) before using real accounts.

## Reporting

Do not include credentials, tokens, account identifiers, private authorization links, enterprise screenshots or document contents in public issues.

If this repository offers GitHub's **Report a vulnerability** option under Security, use it for a private report. If that option is unavailable, open a minimal issue requesting a private reporting channel, without exploit details or sensitive data. A maintainer must establish that channel before you send the details.

Include the affected revision, a sanitized reproduction, impact, and any proposed fix. This policy does not imply that private reporting has already been enabled or guarantee a response time.
