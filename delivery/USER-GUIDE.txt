企业微信 Bot 自动续期｜给使用者

用途：在权限过期前自动续期，完成后关闭权限页。日常由系统脚本运行，不需要 AI 常驻或每周手动操作。

适用：Mac，企业微信5.0.13中文版；本次实测为 macOS 26.4.1 Apple Silicon。企业微信须登录 Bot 创建者主账号，维护自己创建的 Bot。其他客户端版本需适配和验收；Windows暂不支持。首次安装需要联网下载 Python 等依赖，可能需要一次系统权限或首次业务权限确认。

开始使用
1. 把ZIP解压到准备长期保留的位置；安装成功后不要移动或删除。
2. 用 WorkBuddy、Codex 或 Kimi Code 打开解压后的整个文件夹。Agent需要能操作本机文件、终端和企业微信。
3. 发送下面这段话，可加上你的企业、Bot名称和所需权限：

请按 AGENTS.md 和 delivery/AGENT-RUNBOOK.md 为我安装自动续期。先查清本机 Bot、组织和已有 CLI 配置，维护我指定且由当前主账号创建的 Bot；把续期入口放在本机与它的私聊中，只维护我需要的权限，保留其他 Bot 和服务。完成真实续期、自然定时、自动关页的实测，再安装登录后自动加载的每小时任务，在到期前24小时续期。失败请定位、修复并复测，不要只登记任务就报成功。最后给我本机结果卡和停用方式。

安装完成时应收到：组织/Bot/权限名称、真实续期和定时结果、每小时运行安排、项目与日志位置、停止/恢复方法。没有这些实测结果，不算安装完成。

出现问题：把原文件夹交给Agent，说“检查现有任务和最近结果，保留Bot绑定与恢复记录，定位失败后复测”。不要自己重新创建Bot或删除配置。
不再使用：让Agent“持久停用这个Bot的续期任务，下次登录也不再自动启动；保留配置和恢复记录”。它不需要退出企业微信或停掉其他服务。

电脑须开机、桌面可操作、企业微信保持登录。每台新设备须验收后启用；本轮实际安装演练用Kimi，WorkBuddy未实机验证。无需把账号密码、Secret、个人配置或聊天记录发给分发者。
