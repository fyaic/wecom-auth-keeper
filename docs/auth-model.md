## 1. 三层鉴权模型

```
调用方 ──(Bot ID+Secret, 长期)──> bootstrap(qyapi.weixin.qq.com/cli)
        ──(24h access token)──> API 网关
                                   ├── 读接口 ←「搜索与获取文档内容」能力授权(7天线①)
                                   └── 写接口 ←「新建与编辑文档」能力授权(7天线②)
```

- **token 层（853004）**：24 小时寿命（三点贴边实测：23h48m 成功写 / 23h59m55s 成功读 /
  26h54m 首撞 853004）。撞期客户端自动 bootstrap 换新 + 原请求重放一次，**读写共用同一
  token、同一 Bearer 注入点、同一刷新状态机**（二进制逆向：全二进制唯一
  `format!("Bearer {}")`，两个调用点都在同一 transport 状态机）。**此层无需任何人工。**
- **能力授权层（850003）**：服务端按工具粒度维护、**读/写独立计时、各 7 天**、锚定授予
  时刻整点到期。`auth show --status` 只看本地凭据，**服务端已拒绝时仍显示 authorized**
  （静默失效）；CLI 客户端对 850003 零处理原样透传。

## 2. 关键实证（证据强度从高到低）

1. **服务端 UI 直接确认**（2026-09-07 授权页截图）：「新建与编辑文档」有效期至 9/11
   10:32（=9/4 10:32 auth init 扫码 +7d，分秒不差）；当日 15:26 经续期链接重授后页面显示
   「搜索与获取文档内容」有效期至 9/14 15:26（=点击时刻 +7d）。**读写两行独立时间戳并排
   显示**。
2. **读线整点死亡**（2026-09-07）：最后存活证据 14:11，死亡观察 15:18——死亡窗口恰含
   8/31 15:04 授予 +7d = 9/7 15:04 整点。期间每天有探针 + 真实业务调用 → **usage 不续期**。
3. **读写镜像事件**（2026-09-04 / 09-07）：同一凭据同一进程相隔 2 秒，读绿写死（9/4）
   / 读死写绿（9/7，含 bot 自有测试表——**自有文档不豁免能力授权**）→ 分叉在服务端、
   且按操作维度。
4. **token 无关性**（9/4）：写死时 token 刚刷新 ~2 秒（模型推断，被随后重扫覆盖不可
   直接观测）。
5. **上游零先例**：850003 不在官方错误码表（853 族整族缺席）；"持续调用是否续期"在
   #87 被公开追问两月无官方回答；官方唯一记载的续期姿势 = 人工点机器人推送的续期链接
   ——**该主动推送实测从未发生**（创建者收件箱零消息）。

## 4. 企微桌面 GUI 自动化踩坑实录（通用知识）

1. **CEF 输入合成**：CGEvent 键盘/粘贴对企微网页面板**无效**（值都进不去）；有效原语是
   **System Events AppleScript 定向按键**（`tell (first application process whose unix id
   is PID) → keystroke ...`，ASCII 稳定、中文 keystroke 会被打成 'a'、Cmd+V 粘贴稳定）；
   AXValue 赋值能进值但不触发面板逻辑。
2. **聊天区是唯一稳定地面**：消息气泡/链接（AXLink）稳定可读可点；工作台磁贴按最近
   使用**动态排序**；全局搜索面板的结果行进 AX 树 >20s 且时有时无。
3. **AX 文本三坑**：零宽字符（\u200b 等，精确匹配前必清）；行名可能在 AXValue 而非
   AXTitle（取 title-or-value）；控件坐标随窗口位移（关联用相对 Δ）。
4. **多进程互斥**：GUI 自动化必须用 observe/暂停包裹消息监控；异步业务消息处理（agent
   切会话）会随手关掉浮层面板——**深夜是天然独占窗口**（机器需不休眠）。
5. **launchd 无 cwd**：依赖 .env 的库（pydantic Settings 从 cwd 找配置）必须在 import 前
   chdir——两次实战事故的根因（交互测试永远测不出）。
6. **聊天历史区对所有合成滚动免疫**（滚轮/PageUp/拖滚动条均无效，像素差分验证；
   授权页 webview 却可滚——同为 webview 行为不一致）：任何依赖滚动聊天历史的路线不可行。
7. **工作台磁贴按最近使用动态重排，但格位固定**：实测修正的 4×3 格心坐标
   （x=205/425/645/865，y=190/350/510 pt，窗口 960×736）逐格点探 3/3 全中目标应用——
   猜坐标必死，固定格位点探可行；每点后验证落点、未中回退再点下一格。
8. **两处搜索框（全局搜索面板/工作台搜索）下拉均不响应粘贴输入**（值能进、
   结果不渲染；仅手工键入触发）——凡需输入的导航面优先绕开。
9. **夜间无人窗口是 GUI 自动化的必要条件**：业务消息触发 agent 切会话会随手关闭
   浮层面板（工作时段平均 30-60 秒一次），任何多跳流程白天无法完成。
10. **工作台落地页自身会变脸**（应用网格 ↔ 个性化卡片视图随使用漂移）——凡以工作台
    为入口的自动化必须每跳验证 + 失败即时截图归因；固定坐标格阵只在"当前恰为网格视图"
    时有效。**验证器与点击同等重要**：验证谓词漏判 = 点中了也不知道（本次 55 格全空的
    假阴性教训）。
11. **假日全天 = 最佳攻坚窗口**（企业休息日零消息流，等效于无限延长的工作日午夜窗口）。
