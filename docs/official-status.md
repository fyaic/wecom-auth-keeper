## 谁会受影响

直接相关的是使用需要定期重授的智能机器人业务能力、希望长期运行的工作流，例如文档读取、表格写入与通讯录查询。是否受影响，应以实际能力行有效期及错误响应为准。

**不能推断所有使用 wecom-cli 或企业微信的项目都必然遇到相同问题。** 单纯 WebSocket 收发、普通自建应用接口、90 天数据权限、文档成员权限、插件 API 兼容性、消息历史查询窗口，均不能与七天能力授权混为一谈。权限页本身无法授权的服务端错误也不是本项目已经验证解决的问题。

## 临时方案的价值与边界

本项目已证明：预先打开正确权限页后，独立 macOS 脚本能按白名单完成文档读写与通讯录三项取消/重授，并核对新的七天有效期。它能减少适用环境中的重复点击，提供状态输出与中断恢复记录。

完整管理页导航、纯服务器运行、新版业务 API 复探及跨周期无人值守尚未验收。取消与重授期间有短暂权限缺口。因此对外描述应使用“有前置条件的临时桌面续期方案”，不能称为官方替代接口、永久授权或已完成的全自动长期保活。

若官方发布按能力的 `expires_at` / `needs_reauth`、管理员可控长期授权或续期接口，应优先评估官方路径并更新这份记录。
