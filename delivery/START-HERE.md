# 把这个文件夹交给你的 AI 助手

这是企业微信 Bot 自动续期工具的 **macOS 内部验收候选包，尚不能当作已验证版本发给业务侧**。Windows 暂无自动续期后端。不是企业微信官方产品。

解压到固定位置，用 Codex、WorkBuddy 等能够操作本机文件、终端和企业微信的 Agent 打开整个文件夹，发送：

> 请阅读 delivery/AGENT-INSTALL.md 和 delivery/FIRST-RUN.md，为本机安装企业微信 Bot 自动续期。先读取现有 wecom-cli 的配置与官方身份，通过 existing_entry.py 取得原始续期链接；已有绑定不要重新扫码或换绑。找到这个 Bot 的正确组织，再从已核验的 Bot 详情建立本机私聊，把原链接发进去一次。不要假定我已经有私聊和链接。确认换到其他会话后，后台脚本仍能找到入口、打开正确权限页并关闭，再验真实续期和定时运行。保留其他 Bot 和服务，不向我要 Secret。业务权限按实际需要配置；最后分别告诉我“入口准备”“真实续期”“定时运行”是否通过。

可以补充一句：“我要用于××企业的××业务，需要文档/消息/微盘等权限。”已经有 Bot 就告诉 Agent 名称；不知道时让它先查看本机配置与企业微信。有多个候选时，它应给出查到的具体选项，不让你抄 ID 或配置文件。

已有 CLI 绑定的设备不需要重新扫码。只有确实从未绑定且你要求首次接入时，才另行走官方接入；系统辅助功能和首次新增业务权限可能需要你确认。日常定时续期由脚本运行，无需每周再打开 AI。电脑需要开机、企业微信登录且桌面可操作。收到新客户端不兼容提示时需重新验收，不能保证任意 Mac/企业微信版本均可运行。
