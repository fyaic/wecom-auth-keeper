# 把这个文件夹交给你的 AI 助手

这是企业微信 Bot 自动续期工具的 **macOS 内部验收候选包，尚不能当作已验证版本发给业务侧**。Windows 暂无自动续期后端。不是企业微信官方产品。

**使用前提：这台 Mac 的企业微信登录 Bot 创建者的主账号，续期的是这个主账号自己创建的 Bot。** 只有 CLI 配置或能调用 Bot 的业务账号，不满足这个前提。主账号仍需处于正确组织，且电脑开机、桌面可操作。

解压到固定位置，用 Codex、WorkBuddy 等能够操作本机文件、终端和企业微信的 Agent 打开整个文件夹，发送：

> 请阅读delivery/AGENT-INSTALL.md和delivery/FIRST-RUN.md，为我指定的Bot安装自动续期。先锁定这个Bot和组织，再读取其官方身份、匹配已有wecom-cli配置；默认CLI绑定其他Bot时不能替换我的目标。确认当前企业微信主账号是该Bot创建者，再从它的详情建立本机私聊，把原始续期链接放进去一次。保留其他Bot和服务，不向我要Secret、不擅自重建或换绑。验证离开会话后脚本能找回并关闭页面，再验真实续期和定时触发；分别报告目标匹配、账号前提、入口、续期、定时结果。

可以补充一句：“我要用于××企业的××业务，需要文档/消息/微盘等权限。”已经有 Bot 就告诉 Agent 名称；不知道时让它先查看本机配置与企业微信。有多个候选时，它应给出查到的具体选项，不让你抄 ID 或配置文件。

已有 CLI 绑定的设备不需要重新扫码。只有确实从未绑定且你要求首次接入时，才另行走官方接入；系统辅助功能和首次新增业务权限可能需要你确认。日常定时续期由脚本运行，无需每周再打开 AI。电脑需要开机、企业微信登录且桌面可操作。收到新客户端不兼容提示时需重新验收，不能保证任意 Mac/企业微信版本均可运行。

设备上的 CLI 已绑定，不代表当前登录的企业微信账号有权给它续期。若官方页面要求“机器人创建者”，Agent 应保留配置并说明需要哪个身份/组织，不能要求你重新创建 Bot 来掩盖问题。只有本机真实续期和定时触发均通过，才能报告安装完成。
